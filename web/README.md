# Dulce Momento — Web

Sitio de pastelería boutique con estética cute anime y productos realistas.

## Páginas

- `/` — Inicio
- `/menu.html` — Menú con filtros
- `/sobre-nosotros.html` — Historia
- `/contacto.html` — Formulario de contacto

## Desarrollo

```bash
cd web
npm install
npm run dev
```

Abre http://localhost:5173

## Build

```bash
cd web
npm run build
npm run preview
```
